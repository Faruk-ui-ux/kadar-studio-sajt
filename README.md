# Kadar Studio

Statični sajt (HTML + Vue 3, bez build koraka). Otvori `index.html` ili objavi preko GitHub Pages.

- `index.html` — stranica i stilovi
- `js/app.js` — logika (galerija, cijene, forma, animacije)
- `js/vue.global.prod.js` — Vue 3
- `img/` — fotografije

Zauzeti datumi: u `js/app.js` potraži `const zauzeto`.
Broj za WhatsApp: `const broj`. Email: `const mail`.
